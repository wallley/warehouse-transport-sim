# 课程出处与问题背景

本项目来自山东大学控制科学与工程学院自动化专业《高级程序设计与实践》课程，以及 2025 年第七届“学以致用”编程能力大赛的环形轨道穿梭车题目。学院正式名称与自动化专业信息见[山东大学学院介绍](https://control.sdu.edu.cn/info/1057/2541.htm)。这里整理课程背景和建模要求，帮助同学按关键词找到相关学习资料。

课程作业原先集中在一个 C++ 源文件中。本仓库在已有代码基础上按职责拆分模块，保留调度策略、状态转换与 EasyX 界面，并增加无图形运行入口。课程原文档、个人信息表、旧仿真结果和提交压缩包未纳入公开仓库。

## 要解决什么问题

多辆穿梭车在单向环形轨道上运行，将货物在自动化仓储接口和人工出入库站台之间搬运。调度需要同时考虑货物是否就绪、目标设备是否空闲、车辆当前位置以及前车距离。

| 设备编号 | 设备类型 | 作用 |
| --- | --- | --- |
| 1、3、5、7、9、11 | 入库接口 | 接收车辆送来的货物，等待堆垛机取走 |
| 2、4、6、8、10、12 | 出库接口 | 准备从仓库取出的货物，等待车辆取货 |
| 13、14、15 | 出库口 | 接收出库货物，等待人工取走 |
| 16、17、18 | 入库口 | 由人工放置入库货物，等待车辆取货 |

总计 18 个站点。课程任务列表共有 108 条订单，其中 54 条入库、54 条出库；仓库使用代码中的同一组内置订单。订单编号为 1—108，物料编号为 `TP001`—`TP108`。

同一来源设备的任务必须按任务编号先后执行；不同来源设备之间不要求全局编号顺序。每个来源设备初始已经准备好该设备的第一个任务。

## 课程给定的车辆与设备参数

| 参数 | 课程要求 |
| --- | --- |
| 直轨最大速度 | 160 m/min，约 2.667 m/s |
| 弯轨最大速度 | 40 m/min，约 0.667 m/s |
| 加速度与减速度大小 | 0.5 m/s² |
| 车辆长度 | 2000 mm |
| 前后车身最小净距 | 200 mm |
| 一次装货或卸货时间 | 7.5 s |
| 出库接口准备货物 | 50 s |
| 入库口人工放货 | 30 s |
| 出库口人工清货 | 30 s |
| 入库接口等待堆垛机取货 | 25 s |

车辆只能单向行驶，不得碰撞或超车；装卸货物时必须停止，目标设备无货时才能放货。代码以毫米和秒为内部单位，默认固定仿真步长为 0.05 s。

## 两项课程任务

**任务一：巡游与运动记录。** 按实际物理尺寸比例绘制场景，让三辆车以随机速度巡游一圈并随机在出入库口停车。记录加减速阶段的起止时间、速度和加速度，以及总运行时间和停车次数。显示仿真时钟与倍率，并支持调整仿真速度。

**任务二：货物调度与系统分析。** 完成指定的 108 条订单，分别考察 3、5、7 辆车。记录任务准备、取货、放货及货物离开目的设备的时间；记录设备有货/无货变化；统计设备占用、空闲等信息。在不改变轨道及仓储接口位置的前提下提出布局改进建议。

课程要求的初始状态是所有车辆静止，第一辆车与 15 号出库口对齐，其余车辆车身间隔 200 mm。原程序在初始车距、巡游停车与圈数判定等方面采用了不同处理，详见[实现限制](LIMITATIONS.md)。

## 适合从这里学习什么

- 将课程单文件程序拆成模型、轨道计算、调度、运动、日志和界面模块。
- 用状态机描述站点准备、车辆取送货和订单进度。
- 用环形前向距离实现一个易理解的贪心调度策略。
- 用无图形入口重复运行相同配置，并把界面效果与算法验证分开。

如果你的课程题目发生了变化，请先核对当年的参数与评分要求，再参考实现。这个仓库提供已有课程项目的代码阅读与改进起点。
